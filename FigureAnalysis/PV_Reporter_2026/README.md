# PV Reporter Organoid Figure Analysis

Scripts for generating publication figures and statistical analyses
of parvalbumin (PV) expression and BiVe3/BiVe4 reporter specificity
and coverage in medial ganglionic eminence organoids (MGEOs).

## Final publication analyses

### Panel A
- PV-positive cell density (nuclear-associated PV cells/mm²).
- Nuclear-associated PV-positive area (% projected organoid area).
- Kruskal–Wallis tests across H1, H1 CL32, and H1 CL23.
- Holm-adjusted pairwise Mann–Whitney comparisons.

Final script:
pv_panelA_kw_corrected/pv_panelA_kw_and_BC_descriptives.py

Slurm:
pv_panelA_kw_corrected/run_pv_kw.sbatch

### Panels B and C
- BiVe3 and BiVe4 reporter specificity and coverage.
- Descriptive statistics: mean, SD, n, median, and related measures.
- No inferential tests included in the final B/C analysis.

### Original publication figure generation
pv_figure_analysis/pv_figures.py

### Sample verification
verify_pv_figure_samples.py

## Data

Final selected dataset:
35 acquisitions (BiVe3: 17; BiVe4: 18).

Input:
_PV_selected_figures/per_acquisition_metrics.csv

The input CSV is generated by the upstream image-analysis workflow
and is not included in this code archive.

## Important

pv_figure_analysis/pv_variance_diagnostics.py and
pv_panelA_kw_pkg/ contain exploratory/earlier analyses and are
retained for reproducibility.

Use pv_panelA_kw_corrected/ for the final Panel A statistical figures.

The Kruskal–Wallis tests do not adjust for experimental batch.
Acquisition counts should not be interpreted as independent
biological replicate counts without verification.
